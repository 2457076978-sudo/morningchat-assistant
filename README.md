# Morning Chat Assistant · 盲听助手

A browser extension that brings **blind-listening training** to any video/audio page.

盲听训练浏览器插件：在 B 站等网站看视频/听音频时，没听清就点一下——自动**逐层降速重听**（0.8x → 0.6x → 循环磨耳朵），最后才显示中文意思，然后回到原速继续播放。

## Features

- Works on major video/audio sites (Bilibili and more)
- One tap = replay the current sentence slower (0.8x → 0.6x)
- Third tap = loop the sentence until you get it
- Shows the Chinese meaning only at the last step, then auto-resumes at normal speed
- All processing happens locally in your browser — no account, no tracking

## Install

1. Download / clone this repo
2. Open `chrome://extensions` (or `edge://extensions`)
3. Enable **Developer mode**
4. Click **Load unpacked** and select this folder

Also available as a zip from the companion site: http://1.14.103.115/plugin.html
