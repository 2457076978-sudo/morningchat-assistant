# 盲听助手 · 多站版 v2.3（自用试用）

单击递进降速：没听清就点一下 → 本句 0.8x → 再点 0.6x → 再点**循环磨耳朵**。v2.3：**面板分页管理、深浅色自适应、复习页全面重做**。

## v2.3 更新

- **面板分区**：设置面板改为三页签——**交互**（档位/回退/灵敏度/回原速）/ **数据**（触发统计）/ **录制**（内录+快捷键速查）；底部常驻迷你快捷键条
- **深浅色适配**：面板与 HUD 自动跟随站点主题（B站夜间/YouTube 暗色自动切深色）；底部"深浅:自动"可手动循环切换（自动→浅→深）
- **复习页重做**：
  - **音频直接内嵌**（≤28MB 时）：导出的复习页**双击即用**，不用再找文件载入；超长录音才退回拖拽载入模式
  - **波形图 + 标记旗**：整节波形可视化，所有难点位置插旗（当前句高亮区间 + 播放头），点波形任意处跳转
  - **完整梯子语义**：空格 0.8x→0.6x→∞循环，**非循环档听完自动回原速继续**（与插件一致），X 立即回原速，`[ ]` 上一处/下一处难点
  - 深色自动适配，字号/留地重排

## 学习期录制（v2.2 新增）

按 **G**（或面板按钮）开始 → 弹出分享窗口，选**「本标签页」**并**勾选"同时分享标签页音频"** → 正常听课，期间每次触发（S/单击/线控）自动记录：**录音时间点、该句起止区间、降速深度（①②∞）、字幕原文**（有字幕时）→ 再按 **G** 结束，自动下载 3 个文件：

| 文件 | 内容 |
|---|---|
| `盲听期-xxx.webm` | 本节完整音频（内录） |
| `盲听期-xxx.标记.json` | 全部触发标记（机器可读，可进分析管线） |
| `盲听期-xxx.复习页.html` | **精听复习页**：打开后载入同名 webm，列出全部难点句——点击跳转、空格逐级降速循环本句、X 回原速，操作习惯与插件一致 |

录制中主按钮带红圈提示；音频文件仅存本机。

## 安装 / 更新（Chrome 或 Edge）

1. `chrome://extensions` → 打开右上角**开发者模式**
2. **加载已解密的扩展程序** → 选择本文件夹 `extension/`
3. 更新：扩展卡片 **↻ 刷新** → 目标网站页面 **F5**（当前版本 2.1.0）

## 支持站点（18 个匹配规则，14+ 站）

| 档位 | 站点 | 说明 |
|---|---|---|
| **全功能**（字幕分句或静音分句） | B站、YouTube、TED、网易公开课、中国大学MOOC、知乎、微博、西瓜视频、抖音网页版 | 有字幕自动捕获（B站/YouTube）；无字幕用静音分句 |
| **降级档**（固定回退 ±8s + 全套变速/循环） | 腾讯视频、爱奇艺、优酷、Vimeo、BBC Learning English、British Council | DRM/跨域站点音频不可分析，自动切固定回退并提示；核心交互（单击降速/循环/自动回原速）完整可用 |

**安全机制**：接管音频前先探测（DRM 加密源不接管；跨域无 CORS 的源先 HEAD 试探，失败即放弃）——绝不会把视频搞成静音；万一遇到异常静音，刷新页面即可恢复。

## 键盘控制（v2.1 新增）

| 键 | 功能 |
|---|---|
| **S** | 触发：逐档降速重听本句（与点按钮等效） |
| **L** | 直接进入 / 退出循环磨耳朵 |
| **X** | 立即结束复读，回原速续播 |
| **[ / ]** | 上一句 / 下一句（有分句数据按句跳，无则 ±8 秒） |
| **, / .** | 回退 / 前进 3 秒（微调） |
| **P** | 开关设置面板 |
| **G** | 开始 / 结束学习期内录（导出音频+标记+复习页） |

输入框打字时快捷键自动失效；耳机线控、浮钮点击、快捷键三通道等效。

## 其余功能（沿用 v2.0）

1–4 档客制化 · 循环磨耳朵 · 触发统计（本视频/全站累计/难点 Top3 点击跳转）· 字幕智能分句（间隙>0.45s 或句末标点断句）· HUD 分句来源标注（字幕句/静音句/固定回退）· 按钮拖动记忆 · 设置持久化 · 实时预览。

## 已知限制

- 各站播放器实现不同：极少数站点可能被其自带播放器抢回变速（插件会纠正，若反复被抢属站点限制）
- DRM 站点的会员内容分句降级为固定回退；字幕捕获依赖站点自身加载字幕
- 未做逐站实测的站点以降级档保护启动，遇到问题反馈站名即可
